# Mini Games: сайт с мини-играми

Адаптивный сайт с коллекцией интерактивных мини-игр. Учебный проект для практики HTML, CSS и JavaScript.

## Игры

* Угадай число
* Арифметическая игра
* Переворот текста
* Камень, ножницы, бумага
* Викторина
* Генератор случайного цвета

## Технологии

* HTML5
* CSS3
* JavaScript
* SCSS
* БЭМ
* Flexbox и CSS Grid
* Адаптивная вёрстка

## Особенности

* Интерактивная логика игр на JavaScript
* Адаптивная версия для мобильных устройств
* Hover-эффекты и анимации
* Отдельные игровые блоки
* Корректное отображение на разных размерах экрана

## Запуск локально

Клонируйте репозиторий:

```bash
git clone https://github.com/mashapavlenko/mini-games.git
```

Откройте файл `index.html` в браузере.
